# Contributing

Thanks for helping. This project works best when marketers who use these modules every day improve them.

## Ways to help

- **Fix or improve a module.** Found a gap in the brief template or a better question to ask? Edit the file and open a pull request.
- **Add an example.** Real-world style examples (with names and numbers anonymized or fictional) are the most valuable contribution.
- **Propose a module.** Open an issue describing the problem, who has it, and how often.
- **Report a mistake.** Open an issue with what's wrong and, for factual content, a link to the official source.

## Rules for every module

1. A module lives in `modules/<module-name>/` with a `README.md` and a `SKILL.md`.
2. `SKILL.md` starts with `name` and `description` frontmatter. The description says what the module does and when to use it.
3. Factual claims cite an official source and a "last verified" date.
4. Include at least one weak-input example and one strong-output example.
5. No real client names, confidential data, or copyrighted material.
6. Keep it plain text so it works across assistants.

## Pull request checklist

- [ ] I tested the change with an AI assistant on at least one real-style task.
- [ ] Facts I added have a source and date.
- [ ] I added or updated an example if behavior changed.
